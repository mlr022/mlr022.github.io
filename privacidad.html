Política de privacidad

Última actualización: 6 de noviembre de 2026.

1. Datos que usamos

Al autorizar la herramienta con TikTok, recibimos solo lo necesario para publicar: la información básica de la cuenta (identificador, nombre visible y avatar, permiso user.info.basic) y el permiso para publicar vídeos (video.publish), además del token de acceso.

2. Para qué

Únicamente para subir y programar los vídeos del canal @irisloexplica y comprobar que se publicaron. No vendemos, cedemos ni usamos estos datos para publicidad.

3. Dónde se guardan

El token se guarda solo en el ordenador del titular del canal, en una carpeta privada. No hay servidores ni bases de datos de terceros.

4. Cuánto tiempo

Mientras la autorización esté activa. Al revocarla desde TikTok (Ajustes → Seguridad → Apps con permisos) o al pedirlo por correo, se borra el token.

5. Tus derechos

Puedes pedir acceso, corrección o borrado de tus datos escribiendo a irisloexplica@gmail.com.

6. Datos de YouTube

El canal también usa la API de YouTube para sus propios vídeos; esos datos siguen la Política de privacidad de Google.
